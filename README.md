# チーム開発演習(Git/GitHub)　最終課題　レベル1
## 概要
このリポジトリのWebサイトを、自分のオリジナルサイトに修正する
- 既存のコードを解析し、ページの構造やBootstrapの使われ方を理解した上で、自分のオリジナルサイトへ内容を変更する  
- コードの構造や記述方法を把握しながら、必要に応じて整理・改善（リファクタリング的作業）を行う  

## このリポジトリのWebサイトについて
HTMLファイル9つ、CSSファイル2つ、JSファイル2つ、imagesフォルダで構成されています。  
既存コードを解析してもらえれば分かりますが、すべてのリンク先にページが用意されているわけではありません。ページを用意していないリンクについては、自分自身への遷移となっています。どこをクリックするとどういう動きをするか、も解析した上で実装に取り掛かってください。 (リンク先がない部分のページを新たに制作して増やしていただくのは構いません。)   
バックエンドは実装していないので、あくまでも「側(がわ)」の見た目や制御だけです。既存コードでどのようにWebブラウザで動いているか、解析しましょう。(興味がある方以外は、JSを詳しく解析する必要はないです。あくまでも「このボタンが押されたらどういう動きをブラウザ上でしているか？」を解析してください)

## ルール
- 既存のページ構成・大まかなレイアウトは崩さず、オリジナルのWebサイトに書き換えること(`index.html`以外のファイル名の変更はしていいが、ページの削除はしないこと)
- 全体で最低5か所はレイアウトの一部を変更すること(Bootstrapを活用)
    - 色変更ではなく、配置や見え方を工夫すること
    - リンク先がない部分のページを増やすのは、レイアウト変更1つにカウント(ただし既存の別ページと全く同じレイアウトはNG)
    - どこを変更したか、を発表時に聞きますので、「忘れました」や「AIに作ってもらって解析していないので理解していません」ということの無いように
- レスポンシブレイアウトを維持すること(既存はレスポンシブ対応済み)
- 色・フォントは自由に変更可
- ファビコンをWebサイトの内容に合うよう変更すること(レイアウト変更にはカウントしません)
- クローン元のファイルでバグやレイアウト崩れを発見したら修正すること
- コードの可読性を意識すること
    - インデントを揃える
    - **意味のあるクラス名を付ける**
- 使われていないCSSなど、不要なコードを発見したら削除してOK
- Webサイトの概要が分かるREADME.mdを配置すること

## 補足
Issueを立てたり、タスク管理のツールでやらなければならないことを管理しておくと、抜け漏れがなく効率的に作業できると思います。  
また、README.mdに、使用したBootstrapコンポーネントや工夫した点、オリジナル要素をまとめておくと、発表時に説明しやすいかと思われます。

## 手順
1. 任意の場所にcloneする
2. リモートリポジトリをpublicで作成し、cloneしたリポジトリの接続先を、作成したリモートリポジトリに変更する
    ```bash
    git remote set-url origin 自分のリポジトリURL
    ```
3. 作業開始    
    適宜ブランチを切って、作業単位ごとにcommitするなど工夫して作業してください。  
    【ブランチ運用のメリット】
    - 作業内容を分けて管理できる
    - 誤ってmainを壊すリスクを減らせる
4. 作業終了後は、自分のリモートリポジトリにpushする
5. GitHub Pagesで公開する  
    [GitHub PagesでのWebサイト公開手順](https://prog-8.com/docs/github-pages)  
    上記手順の「5 ページの公開」を参考にしてください。
6. Classroomに公開したURLを提出

## 修正した箇所 - (manga-community.html)
漫画のサイトに変更したためisbnコードから本を特定可能になったので卒研の授業で使用した国立国会図書館のAPIを使用したISBN検索をしてみました。
 - 参考サイト (https://qiita.com/saoyagi2/items/5c23550b0a00933386a6)
 - 楽天ブックスAPIとの違い
楽天ブックスAPIは画像は商業利用目的のために余計な画像を取得してくるときがある。
国立国会図書館APIは日本国内で発行された出版物を記録・保存する機関であるらしいので最も最新の本をすべて記録しているてために新しい本でも取得してこれる。また、商業利用目的ではないために無駄な画像もついてこない
1. 初めにhtmlとcssを書く
2. isbnコードをたたいてコンソールでタイトルの取得が成功したか試す
3. 画面に反映させる
